# Python Analytics Homework

A small Python/Pandas exercise repository associated with the GoIT Data Analyst course.

## Current contents

[`analysis.py`](analysis.py) creates a DataFrame with example sales figures for Kyiv, Lviv, and Odesa, prints the table, and calculates the mean sales value. The data is defined directly in the script; no external dataset or credentials are needed.

## Run locally

Requirements: Python 3 and Pandas.

```bash
git clone https://github.com/Shubender/python-analytics-homework.git
cd python-analytics-homework
python -m pip install pandas
python analysis.py
```

For the supplied example data, the mean is approximately `883.33`. Output labels are in Ukrainian.

## Scope

This repository currently contains a single introductory exercise, not a complete analytics portfolio or the full course curriculum. It demonstrates DataFrame creation, tabular output, and a simple aggregate calculation. There is no pinned dependency file or automated test suite.
